# Selzenn

Repositori rilis aplikasi Selzenn.

## SelzennCAD

Rilis Windows x64 SelzennCAD dibangun dari kode CADCraft dan dipadukan dengan identitas serta tema Selzenn. Ambil installer resmi melalui [rilis SelzennCAD terbaru](https://github.com/tokekkesel/selzenn/releases/latest).

Pembaruan di dalam aplikasi hanya memilih tag `selzenncad-vX.Y.Z` dan aset `SelzennCAD-Setup-X.Y.Z-Windows-x64.exe`, kemudian memeriksa ukuran serta SHA-256. Installer CADCraft upstream tidak pernah dipakai sebagai paket SelzennCAD.

Basis kode: [CADCraft](https://github.com/storytold/cadcraft). Lisensi MIT atau Apache-2.0; pemberitahuan, daftar kontributor, dan atribusi upstream tetap disertakan. Situs produk: [selzenn.com](https://selzenn.com).
